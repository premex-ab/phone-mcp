📱 내 휴대폰을 AI의 도구로

Phone MCP는 Android 휴대폰을 Claude 같은 AI 어시스턴트가 연결할 수 있는 안전한 MCP 서버로 만들어 줍니다. 사진 찾기, 다운로드한 PDF 읽기, 센서 확인, 사진 촬영, 연락처 검색을 AI에게 맡기세요 — 모든 기능은 내 기기 안에서, 내 통제 아래 있습니다.

앱 자체에는 AI가 없습니다. Claude Code, Claude Desktop 등 Model Context Protocol을 지원하는, 이미 사용 중인 어시스턴트를 연결하면 됩니다.

🌍 원격 접속 — 신기능
phonemcp.ai를 통해 어디서나 휴대폰에 연결하세요. 새 AI 클라이언트 페어링은 1분이면 충분합니다. 명령어 하나를 실행하고 앱에 표시된 페어링 코드를 입력하면 끝. 페어링된 클라이언트는 자동으로 다시 연결됩니다.

• 어떤 네트워크에서도 작동 — 포트 포워딩, VPN, 계정 생성 불필요
• 일회용 페어링 코드 기반 OAuth 2.1 인가
• 휴대폰은 항상 아웃바운드 연결만 사용
• 릴레이는 휴대폰의 로컬 인증 정보를 절대 볼 수 없음
• 페어링된 AI 클라이언트를 앱에서 확인하고 언제든 해지 가능
• 30일 무료 체험 후 부담 없는 월간 또는 연간 구독

🏠 로컬 네트워크 — 영원히 무료
같은 Wi-Fi에서는 AI가 휴대폰에 직접 연결합니다. 클라우드 없음, 구독 없음, 제한 없음. 로컬 사용은 언제까지나 무료입니다.

🧰 AI가 할 수 있는 일
• 파일 — 사진, 다운로드, 문서 탐색 및 읽기
• 카메라 — 사진을 찍어 바로 모델에 전달
• 센서 — 가속도계, 자이로스코프, 기압계, 조도 등
• 위치 — 휴대폰의 현재 위치
• 연락처 — 사람 검색
• SMS — 메시지 작성(내 확인 후 전송)
• 확장 — 서드파티 앱이 자체 MCP 도구를 제공 가능

🔒 설계부터 프라이버시 우선
• 모든 도구는 기본적으로 꺼져 있음 — 민감한 도구는 명시적 동의 필요
• 로컬은 Bearer 토큰 인증, 원격은 OAuth 2.1
• 원격 접속은 언제든 끌 수 있으며 터널이 즉시 닫힘
• 광고 없음, 트래커 없음, 데이터 판매 없음
